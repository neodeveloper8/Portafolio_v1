¡Bienvenido a mi portafolio personal! Este proyecto es una vitrina de mi trayectoria como desarrollador, mis habilidades técnicas y los proyectos que he construido con pasión por el diseño limpio y funcional.

✨ Características Principales
Estética Esmeralda & Tech: Interfaz moderna con una paleta de colores personalizada en tonos Esmeralda y Cian.

Animaciones Premium: Uso de Lottie Framework para ilustraciones en movimiento y Framer Motion para transiciones fluidas.

Totalmente Responsivo: Diseñado con un enfoque mobile-first usando Tailwind CSS.

Carga Eficiente: Optimización de assets locales y uso de componentes memoizados en React para un rendimiento superior.

Contacto Funcional: Integración con FormSubmit para recepción de mensajes directamente al correo.

🛠️ Stack Tecnológico
Este portafolio fue construido utilizando el ecosistema moderno de desarrollo web:

React 18 (Vite como bundler)

Tailwind CSS (Estilizado de alta velocidad)

Lucide React (Paquete de iconos consistente)

Lottie Files (Animaciones basadas en JSON)

AOS (Animate On Scroll) (Efectos de aparición al hacer scroll)

SweetAlert2 (Notificaciones y modales elegantes)

📦 Instalación y Configuración Local
Si deseas explorar el código o ejecutarlo en tu máquina, sigue estos pasos:

## 🏃‍♂️ Getting Started

Follow these steps to run the project locally:

### 1\. Clone the Repository

```bash
git clone https://github.com/EkiZR/Portofolio_V5.git
cd Portofolio_V5
```

### 2\. Install Dependencies

```bash
npm install
```

If you encounter peer dependency issues, use:

```bash
npm install --legacy-peer-deps
```

### 3\. Run the Development Server

```bash
npm run dev
```

### 4\. Open in Browser

Access the application through the link displayed in your terminal (usually `http://localhost:5173`).

## 🏗️ Building for Production

To create a production-ready build:

1.  Run the build command:

    ```bash
    npm run build
    ```

2.  The build files will be saved in the `dist` folder. Upload this folder to your hosting server.

⚙️ Notas de Implementación
Assets: Las animaciones se encuentran en src/assets/ y se cargan localmente para garantizar velocidad y disponibilidad.

Formulario: El sistema de contacto utiliza axios para enviar datos a FormSubmit. Asegúrate de actualizar tu correo en Contact.jsx.

Vite Config: Se incluyó assetsInclude: ['**/*.lottie'] para el correcto procesamiento de las animacione
